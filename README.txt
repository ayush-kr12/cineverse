CINEVERSE / MOVIE ROULETTE STARTER

This contains the 350 titles you supplied, grouped into the 9 finalized categories, plus a responsive dark/gold interface, search, random picker and local Watched/Unwanted tracking.

INSTALL INTO YOUR EXISTING PROJECT
1. In the PowerShell window running Vite, press Ctrl+C to stop it.
2. Extract this ZIP.
3. Copy the src folder and index.html from the extracted folder into Desktop\movie-roulette, replacing existing files when asked.
4. Open PowerShell and run:
   cd $HOME\Desktop\movie-roulette
   npm.cmd install
   npm.cmd run dev
5. Open the localhost URL printed in PowerShell.

Verified metadata, poster art, synopses, runtimes, watch order and India streaming availability are not filled yet; they should be researched in a later stage. Login/cloud sync is not included in this first version.
